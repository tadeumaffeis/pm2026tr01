# ADR-005 — Identidade global e autorização por processo

## Status
ACCEPTED

## Contexto
Planejamento v1.0 aprovado explicitamente em 17/09/2026. Alternativas: token confirma cada decisão; contas permanentes para apreciadores; sessão por processo.

## Problema
Sustentar o fluxo institucional auditável sem decisões de negócio implícitas ou complexidade operacional injustificada.

## Alternativas consideradas
Alternativas: token confirma cada decisão; contas permanentes para apreciadores; sessão por processo.

## Decisão
Senha temporária autentica identidade; sessão revogável; link por vínculo; aceite e manifestação por ciclo.

## Justificativa
Reflete decisões aprovadas e separa identidade de permissão.

## Consequências
Recusa sem sessão é exceção aprovada; não tratar link como prova inequívoca de autoria; tokens protegidos.
